Können – can, to be able to (können – konnte – hat gekonnt)
S +können + Infinitiv
Ich kann Deutsch sprechen.
S +können + Akkusativ (Sache) + Infinitiv
Ich kann diese Aufgabe lösen.
S +können + bei + Dativ (Situation/Ort) + Infinitiv
Ich kann dir bei der Arbeit helfen.
S +können + mit + Dativ (Sache) + Infinitiv
Ich habe mit dem Computer arbeiten können.
Kosten – to cost
Sache + kosten + Akkusativ (Preis)
Das Buch kostet 20 Euro.
Sache + kosten + Akkusativ (Person)
Das Essen kostet mich viel Geld.
Sache + kosten + Akkusativ (Preis) + pro + Akkusativ (Einheit)
Die Äpfel kosten 3 Euro pro Kilo.
Sache + kosten + Akkusativ (Preis) + mehr/weniger als + Nominativ
Das Auto hat mehr als mein Fahrrad gekostet.
Lassen – to let, to leave, to have something done (lassen – ließ – hat gelassen)
S +lassen + Akkusativ (Person/Sache)
Ich lasse meinen Bruder schlafen.
S +lassen + Akkusativ + Infinitiv
Ich lasse mein Auto reparieren.
S +lassen + Akkusativ (Sache) + Ort
Ich lasse mein Handy zu Hause.
S +lassen + sich + Infinitiv
Das hat sich leicht erklären lassen.
