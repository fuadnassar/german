beglaubigen – يصدق / يوثق (habe ____ beglaubigt)
S +etwas beglaubigen + Akkusativ
Du beglaubigst die Unterschrift.
S +etwas + bei + Dativ beglaubigen
Er lässt das Dokument beim Notar beglaubigen.
S +etwas + offiziell beglaubigen
Ihr müsst die Kopie offiziell beglaubigen.
S +haben + Akkusativ + beglaubigt
Ich habe die Unterschrift beglaubigt.
benötigen – يحتاج / يتطلب (habe ____ benötigt)
S +etwas benötigen + Akkusativ
Du benötigst einen neuen Pass.
S +jemanden/etwas + für + Akkusativ benötigen
Er benötigt den Pass für die Reise.
S +etwas + dringend benötigen
Ihr benötigt dringend Hilfe.
S +haben + Akkusativ + benötigt
Ich habe einen neuen Pass benötigt.
berufen – يعين / يدعو / يستدعي (habe ____ berufen)
S +jemanden + zu + Dativ berufen
Du berufst ihn zum Professor.
S +jemanden + auf + Akkusativ berufen
Er beruft ihn auf eine Professur.
S +sich + auf + Akkusativ berufen
Ihr beruft euch auf das Gesetz.
S +haben + Akkusativ + berufen
Ich habe ihn zum Professor berufen.
